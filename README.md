# 🎙️ 보이스 다이어리 (스마트폰 음성 인식 + 구글 시트 일기장 PWA)

스마트폰 브라우저(iOS Safari / Android Chrome)의 음성 인식 기능으로 말하듯 일기를 쓰고, Google Apps Script를 통해 내 구글 시트에 자동으로 저장·조회하는 개인용 디지털 음성 일기장 앱입니다.

## 📁 프로젝트 구성

- `index.html`, `styles.css`, `app.js`: 모바일 최적화 PWA 프론트엔드
- `manifest.json`, `sw.js`, `icons/icon.svg`: 홈 화면 추가(PWA) 및 오프라인 캐시 설정
- `apps-script/Code.gs`: 구글 시트 연동용 Google Apps Script 백엔드

---

## 1단계: 구글 시트에 Apps Script 배포하기

1. 전용 구글 시트를 엽니다:  
   👉 [나의 음성 일기장 시트 열기](https://docs.google.com/spreadsheets/d/1-sw574Y_Q-oU6nSDJcSlPNj3A4UVh3qjzv-E5mCXpdM/edit)
2. 상단 메뉴에서 **[확장 프로그램] → [Apps Script]** 를 클릭합니다.
3. 편집기에 있는 기본 코드를 모두 지우고, [`apps-script/Code.gs`](./apps-script/Code.gs) 파일의 전체 내용을 복사해서 붙여넣은 뒤 저장(`Ctrl + S`)합니다.
4. 우측 상단 **[배포] → [새 배포]** 를 클릭합니다.
5. 톱니바퀴(유형 선택)에서 **[웹 앱]** 을 선택한 후 아래와 같이 설정합니다.
   - **다음 사용자 권한으로 실행**: `나`
   - **액세스 권한이 있는 사용자**: `모든 사용자`
6. **[배포]** 를 누르고 권한 승인 후 생성되는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 2단계: 앱 실행 및 스마트폰에 설치하기

> **중요:** 스마트폰 브라우저의 **마이크(음성 인식)** 와 **PWA(홈 화면 추가)** 기능은 **HTTPS 환경**에서만 정상 동작합니다.

### 방법 A. 무료 정적 호스팅 사용 (추천)
이 폴더의 파일들을 **GitHub Pages**, **Netlify**, **Vercel** 또는 **Cloudflare Pages**에 올리면 즉시 `https://...` 주소를 받을 수 있습니다.

### 방법 B. PC 로컬 테스트
```powershell
npx serve .
```
(로컬 PC 브라우저에서는 `http://localhost:3000`에서도 마이크 권한이 동작합니다.)

### 스마트폰 홈 화면에 추가
- **아이폰 (Safari)**: 주소 접속 → 하단 공유 버튼(□↑) → **[홈 화면에 추가]**
- **안드로이드 (Chrome)**: 주소 접속 → 우측 상단 메뉴(⋮) → **[홈 화면에 추가]** 또는 **[앱 설치]**

---

## 3단계: 앱 설정 연결

1. 앱 하단 **[⚙️ 설정]** 탭으로 이동합니다.
2. 복사해둔 **Apps Script 웹 앱 URL**을 붙여넣고 **[연결 테스트]** 를 누릅니다.
3. 연결 성공 메시지가 뜨면 **[설정 저장]** 을 누릅니다.
4. *(선택)* **Gemini API 키**를 입력하면 일기 작성 후 **[✨ AI 요약 & 감정 분석]** 버튼을 눌렀을 때 Gemini가 한 줄 요약, 기분, 태그, 공감 코멘트를 자동으로 작성해줍니다. (키가 없어도 기본 요약/감정 분석이 동작합니다.)
